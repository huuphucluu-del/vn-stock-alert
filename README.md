# 📊 VN Stock MA Alert Bot

Tự động quét tín hiệu MA200 · MA50 · MACD cho VN30/VN100 mỗi ngày lúc 16:00 và gửi cảnh báo qua Telegram.

## Tín hiệu phát hiện
- 🟢 Nến ngày cắt lên MA200 — tín hiệu tăng dài hạn
- 🔵 Nến ngày cắt lên MA50 — tín hiệu tăng trung hạn  
- 🟡 MACD cắt lên Signal — xung lượng tăng
- ⚠️ Mã đang gần MA200 (±3%) — theo dõi sắp cắt
